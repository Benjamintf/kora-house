# Kora House — Hotel & Restaurant

A complete multi-page static hospitality website built with semantic HTML, modular CSS, and vanilla JavaScript.

## Pages
Home, Rooms & Suites, Restaurant, Menu, Experiences, Events & Weddings, Gallery, About, Contact.

## Features
- Responsive desktop/tablet/ layout
- Liquid-glass bordered navigation with shadow
- Sticky header +  navigation
- Room filtering by type, capacity, and price
- Menu category tabs
- Gallery filters + accessible lightbox
- Testimonial carousel
- Booking, contact, newsletter, restaurant, and event form validation
- Check-out date validation
- Guest selector
- FAQ accordion
- English / Amharic language toggle for marked content
- Ethiopian-inspired palette, copy, and map asset
- No React, Bootstrap, Tailwind, jQuery, or UI framework

## Run
Open `index.html` directly, or serve the folder from any static host.

## Image note
The demo uses remote Unsplash image URLs for photographic placeholders. Replace them with licensed Ethiopian photography in `assets/images/` before production if desired.
